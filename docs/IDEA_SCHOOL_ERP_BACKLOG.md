# แนวคิด: ระบบบริหารโรงเรียน (School ERP) — เก็บไว้พัฒนาต่อในอนาคต

> เอกสารนี้เก็บโครงเมนู "ระบบบริหารโรงเรียน" ที่เคยอยู่ในเว็บ (หน้า `/school-erp`)
> ถูกถอดออกจากเมนูจริงแล้วเมื่อ 2026-09-21 เพราะทำให้เว็บดูใหญ่/รกเกินไป
> ทั้งที่หลายรายการยังเป็นแค่ต้นแบบ ยังไม่มีหน้าใช้งานจริง
> เก็บไว้ที่นี่เผื่อวันหลังอยากหยิบมาทำต่อทีละหมวด

โค้ดต้นฉบับ (ฟังก์ชัน `build_school_erp_modules`, `build_school_erp_integrated_dashboard`,
เทมเพลต `school_erp.html`, `school_erp_module.html`) ถูกลบออกจากระบบแล้ว
ถ้าจะทำใหม่ ให้เขียนใหม่ทีละหมวดจริง ๆ แทนการทำ hub รวมทีเดียว

## หมวดที่ "ใช้งานได้จริงแล้ว" (มีหน้าเว็บอยู่ในระบบ แต่ตอนนี้ไม่มีลิงก์เมนูให้เข้า)

ฟีเจอร์เหล่านี้มีโค้ด/หน้าเว็บสมบูรณ์อยู่แล้วใน `app.py` (route ยังไม่ถูกลบ)
เพียงแต่ไม่มีเมนูพาไปแล้ว ถ้าจะกลับมาใช้ แค่เพิ่มลิงก์ในเมนูก็พอ ไม่ต้องเขียนใหม่:

- **Phase 3 — ดูแลช่วยเหลือนักเรียน**: เยี่ยมบ้านออนไลน์ (`phase3_home_visits`), แบบประเมิน SDQ (`phase3_sdq`), กลุ่มช่วยเหลือ/บันทึกการดูแล (`phase3_care_records`), แดชบอร์ดรวม (`phase3_dashboard`)
- **Phase 4 — กิจกรรมพัฒนาผู้เรียน**: จัดการชุมนุม/ชมรม (`phase4_clubs`), บันทึกกิจกรรม (`phase4_activities`), แดชบอร์ดรวม (`phase4_dashboard`)
- **Phase 5 — สารบรรณอิเล็กทรอนิกส์**: ทะเบียนหนังสือรับ-ส่ง/คำสั่ง/ประกาศ/บันทึกข้อความ/เกษียน (`phase5_documents`), แดชบอร์ดรวม (`phase5_dashboard`)
- **Phase 1/2**: แดชบอร์ดวิชาการหลัก (`phase1_dashboard`), ผู้ปกครอง + แจ้งขาดเรียนผ่าน LINE แบบเตรียมข้อความ (`phase2_dashboard`, `line_absence`, `phase2_guardian_settings`)

## หมวดที่เป็นแค่ "ไอเดีย" (ยังไม่มีหน้าใช้งานจริงเลย — ต้องเขียนใหม่ทั้งหมด)

| หมวด | ไอเดียฟีเจอร์ |
|---|---|
| 🏦 ระบบออมทรัพย์นักเรียน | เปิดบัญชีรายคน, บันทึกฝาก/ถอน, สมุดบัญชี, รายงานการเงิน |
| 💳 ระบบการเงินกิจกรรม | เก็บเงินกิจกรรม/ทัศนศึกษา, บันทึกชำระเงิน, ติดตามค้างชำระ, ใบเสร็จ |
| 👪 Parent Portal (เวอร์ชันเต็ม) | หน้าล็อกอินผู้ปกครองแยก, ดูผลการเรียน/การมาเรียน/การบ้านแบบอ่านง่าย, แจ้งเตือน LINE อัตโนมัติ |
| 📄 เอกสาร ปพ.5 / ปพ.6 / ปพ.7 | แบบฟอร์มราชการมาตรฐาน พิมพ์ได้ |
| 🧑‍🎓 พฤติกรรม/ความประพฤติ | บันทึกความดี-ความผิด, คะแนนพฤติกรรมสะสม |
| 🗂️ ย้ายเข้า/ย้ายออก/เลื่อนชั้น | แบบฟอร์มทะเบียนรับย้าย, จำหน่ายนักเรียน, เลื่อนชั้นทั้งระบบ |
| 🧑‍💼 เวรประจำวัน / ไปราชการ-ลางาน | จัดเวรครู, บันทึกวันลา |
| 📊 รายงาน PDF/Excel ผู้บริหาร | ส่งออกรายงานสรุปสำหรับที่ประชุม |
| 📝 สุ่มข้อสอบ / วิเคราะห์ข้อสอบ | ตั้งค่าชุดข้อสอบสุ่ม, วิเคราะห์ความยาก/อำนาจจำแนก |

**คำแนะนำเมื่อจะทำต่อ:** เลือกทำทีละหมวดที่มีคนต้องการใช้จริงก่อน (เช่น พฤติกรรม/ความประพฤติ
หรือ ปพ.5-7 น่าจะใช้บ่อยกว่าออมทรัพย์/การเงินกิจกรรม) แล้วเปิดเป็นเมนูจริงทันทีที่ทำเสร็จ
ไม่ต้องรอทำครบก่อนค่อยเปิด จะได้ไม่กลับไปเป็นเมนูใหญ่แต่ว่างเหมือนเดิม
