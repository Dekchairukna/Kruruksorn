# ครูรักสอน

ระบบเว็บสำหรับครู ใช้จัดการรายวิชา ห้องเรียน บทเรียน ใบงาน แบบทดสอบ การสั่งงาน ตารางสอน ปฏิทิน เวลาเรียน และสรุปคะแนนทั้งเทอม

## ความสามารถหลัก
- Login แยกบทบาท: admin / teacher / student
- ครูหลายคนแยกข้อมูลตามเจ้าของงาน
- นักเรียนเห็นเฉพาะงาน/วิชาที่ถูกสั่งให้ห้องของตัวเอง
- เพิ่ม/แก้ไข/ลบ ผู้ใช้ ห้องเรียน รายวิชา หน่วย บทเรียน ใบงาน แบบทดสอบ ข้อสอบ งานที่สั่ง ตารางสอน และปฏิทิน
- นำเข้านักเรียนจาก Excel: เลขบัตรประชาชน | ชื่อ-สกุล | วันเกิด
- Username นักเรียน = เลขบัตรประชาชน, Password เริ่มต้น = วันเดือนปีเกิด
- ใบงานทั่วไปและใบงานเปตองแบบตารางระยะ/สถานี
- แบบทดสอบออนไลน์ ตรวจคะแนนอัตโนมัติ
- เงื่อนไขจบบทเรียน: เข้าเรียน + ส่งใบงาน + ทำแบบทดสอบผ่าน
- ตารางสอนแสดงคาบปัจจุบัน/คาบถัดไป
- ปฏิทินวันหยุด/กิจกรรม/ไปราชการ
- เช็กเวลาเรียน ขาด ลา มาสาย และรายงานนักเรียนที่ขาดเรียนเกินเกณฑ์
- สรุปคะแนนทั้งเทอมและ Export Excel
- แจ้งเตือนผู้ปกครองผ่าน LINE เมื่อนักเรียนขาดเรียน
- UI รองรับมือถือด้วยเมนูแฮมเบอร์เกอร์และตารางแบบการ์ด

ดูประวัติการอัปเดตทั้งหมดที่ [`CHANGELOG.md`](./CHANGELOG.md)
เอกสารอ้างอิงอื่น ๆ (รูปแบบไฟล์นำเข้า, บันทึกการแก้บั๊กระหว่างทาง) อยู่ในโฟลเดอร์ [`docs/`](./docs/)

## รันระบบ
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

ถ้าพอร์ต 5000 ชน ให้รัน:
```bash
PORT=8000 python app.py
```

เปิดเว็บที่ http://127.0.0.1:8000

## ⚠️ ความปลอดภัยของข้อมูล

ฐานข้อมูล (`instance/*.db`) มีข้อมูลนักเรียนจริง รวมถึงเลขบัตรประชาชนที่ใช้เป็น username
ไฟล์นี้ถูกเพิ่มเข้า `.gitignore` แล้วและเลิก track ใน git (`git rm --cached`) แต่ **ยังคงอยู่ในประวัติ
commit เก่าของ repo นี้** ถ้า repo เคย push ขึ้นที่สาธารณะหรือแชร์ให้คนนอกทีมมาก่อน ให้ทำเพิ่มดังนี้:

1. เปลี่ยน repo ให้เป็น private ทันที (ถ้ายังไม่ใช่)
2. ใช้ `git filter-repo` (หรือ `git filter-branch`/BFG Repo-Cleaner) ลบ `instance/krurakson.db`
   และ `uploads/` ออกจากทุก commit ในประวัติ แล้ว force-push ทับของเดิม
3. แจ้งทุกคนที่ clone repo นี้ไว้ให้ clone ใหม่ เพราะประวัติ git จะเปลี่ยน

ถ้า repo นี้เป็น private และไม่เคยแชร์ให้ใคร ความเสี่ยงต่ำ แต่แนะนำให้ทำตามขั้นตอนข้างต้นไว้ก่อน
เพื่อความปลอดภัยระยะยาว
